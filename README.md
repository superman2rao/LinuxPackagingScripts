# LinuxPackagingScripts
It is having scripts for Ubuntu based package Management and official repository downloading purpose for seamlessly.  

getdebpackages.sh script is written for downloading packages from official ubuntu repository, 
where list of packages are provided using a file containing complete package url (e.g., https://archive.ubuntu.com/pool/main/.../package.deb)  

Script1.sh script is written for the use case when we want official dists package list and according to that we want to download all their containing .deb packages
